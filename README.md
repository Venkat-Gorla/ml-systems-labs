# ML Systems Labs

This repository is a collection of focused machine learning explorations built with an **engineering-first, decision-driven** mindset.

## Motivation

This repo reflects a deliberate effort to:

- Build practical intuition across core ML problem types
- Evaluate techniques through **implementation, not theory**
- Apply **software engineering rigor** to ML workflows

Each project is scoped as a POC, but developed with an emphasis on:

- **Production-style code**
- Tests and validation where relevant
- Clear documentation of assumptions and results

## Reading Guide

Each directory is fully self-contained and explores a single ML problem end-to-end.

While problem types vary, every POC follows a consistent decision structure:

| Step         | Focus                         |
| ------------ | ----------------------------- |
| **Framing**  | Problem and expected outcome  |
| **Baseline** | Non-ML or simple approach     |
| **Approach** | Chosen ML method              |
| **Outcome**  | Results, trade-offs, decision |

Any POC can be read independently.
